office-jokes is a tiny program that writes one funny line about office life to a file: an out-of-office note promises a return on Monday, and the inbox, left alone for a week, spends the time applying for the narrator's job.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
